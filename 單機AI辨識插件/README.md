# 扶輪公益網 AI 刊登助手 (單機版)

專為「**扶輪公益網 (17rcn.org)**」設計的個人單機 Chrome 瀏覽器擴充功能（Manifest V3）。  
適合個人電腦端作業、臨時手動選取照片與單機即時辨識。

---

## 🎨 視覺與版面特色

- **緋紅色主題 (Crimson Red: `#e22e4c`)**：搭配專屬緋紅 AI 機器人圖示，與團隊整合版（翡翠綠）形成強烈視覺對比，絕不混淆。
- **簡潔折疊卡片「⚙️ 偏好設定」**：
  - 將「Gemini API Key」、「AI 辨識模型」、「常用所在地地址」、「防送出衝突保護」四大設定收納至折疊卡片中。
  - **智慧狀態感知**：未設定 API Key 時自動展開提示填寫；已設定完成後預設折疊收納，維持主畫面極致乾淨。

## ✨ 核心功能與特色

### 1. 精準多模態 Flash 自動調度
- **推薦選項**：預設為 **`✨ 自動選擇最新 Flash (推薦)`**。
- **視覺主力精準過濾**：自動向 Google API 查詢可用模型，徹底排除純語音 (`-tts`)、生圖 (`-image`)、向量 (`embedding`) 等無法分析照片的變體。
- **版本數值排序**：標準主力模型（如 `gemini-3.8-flash`、`gemini-3.7-flash`）依版本數字大小排列，確保自動調度永遠命中最新的視覺正式版。
- **支援自訂模型**：專責人員亦可隨時在下拉選單中手動指定特定模型。

### 2. 智慧表單填寫技術
- **動態 AJAX 二級分類等待**：自動選取 27 大類後，主動觸發 jQuery change 事件，非同步等待二級分類選單載入完成後依代碼精確選中。
- **KindEditor 富文本編輯器三重同步**：
  1. 主世界 API 呼叫 `window.editor.html()` 與 `sync()`。
  2. Content Script 穿透 `iframe.ke-edit-iframe` 視覺層直接寫入 HTML。
  3. 底層隱藏 `textarea#editor1` 備援賦值，確保 100% 寫入資料庫。
- **twzipcode 台灣地址智慧解析**：
  - 內建台灣 22 縣市與 368 鄉鎮市區字典。
  - 使用者在設定中儲存單一完整地址（如 `新北市板橋區縣民大道二段7號`），外掛自動分拆縣市、行政區與路名，並連動網頁下拉選單。
- **常用選項自動預設**：媒合期限 90 天、建議索取方式自送、誰能索取為任何單位。

### 3. 防重複送出保護盾 (Anti-Double-Submit)
- 覆寫底層 `form.submit` 阻斷 jQuery Validate 與 Google reCAPTCHA 觸發的連鎖二次調用。
- 按鈕點擊後即時進入鎖定狀態，防止連點。
- 監聽原生隱藏 `iframe[name="jc"]` 回應後才延遲解鎖，並具備 45 秒逾時保護。可於設定選單隨時開關。

### 4. 隱私安全與本機儲存
- API Key 與個人地址完全保存在瀏覽器本地 `chrome.storage.local`，不經由任何第三方伺服器。
- 提供最近 20 筆刊登紀錄查閱，說明文字支援一鍵複製。

## 🚀 安裝與使用教學

### 步驟 1：載入擴充功能
1. 打開 Google Chrome 瀏覽器，前往 `chrome://extensions/`。
2. 開啟右上角 **「開發人員模式」**。
3. 點擊左上角 **「載入未封裝項目」**，選取 `扶輪公益網插件/單機AI辨識插件/` 資料夾。

### 步驟 2：初次設定
1. 點開瀏覽器工具列上的緋紅機器人圖示。
2. 展開「⚙️ 偏好設定」：
   - 輸入您的 **Gemini API Key**（可於 [Google AI Studio](https://aistudio.google.com/) 免費取得）。
   - 模型選擇保持 **`✨ 自動選擇最新 Flash (推薦)`** 即可。
   - 輸入您的常用 **所在地地址**。
3. 點擊「儲存設定」，設定卡片將自動收合。

### 步驟 3：開始刊登
1. 前往扶輪公益網「刊登資源」頁面 (`goods_add.php`)。
2. 在網頁上選擇 1～3 張物資照片。
3. 點開插件彈出視窗，點擊 **「🤖 AI 自動填寫」**。
4. 約 3 秒後表單自動填寫完成，檢查無誤後輸入右側驗證碼即可送出！
