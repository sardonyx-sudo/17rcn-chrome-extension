# 扶輪公益網 AI 刊登助手 (Chrome / Edge 電腦端擴充套件)

本專案為「**扶輪公益網 (17rcn.org)**」電腦瀏覽器專用之自動化刊登擴充套件，全面相容 **Google Chrome**、**Microsoft Edge** 及所有 Chromium 核心瀏覽器。

---

## 🛠️ 安裝教學（免商店審查・1分鐘快速安裝）

本套件為「未打包擴充功能」，安裝極為簡便：

### 步驟 1：下載並解壓縮
1. 點擊本頁面右上角綠色的 **「Code」➔「Download ZIP」**（或自 Release 下載 ZIP 檔）。
2. 下載完成後，**在電腦上將 ZIP 檔完全解壓縮**成一個一般資料夾。

---

### 步驟 2：開啟瀏覽器擴充功能頁面
- **Google Chrome**：在網址列輸入 `chrome://extensions/` 並按 Enter。
- **Microsoft Edge**：在網址列輸入 `edge://extensions/` 並按 Enter。

---

### 步驟 3：開啟「開發人員模式」
- **Chrome**：將畫面右上角的 **「開發人員模式 (Developer mode)」** 切換開關開啟。
- **Edge**：將畫面左側選單下方的 **「開發人員模式」** 切換開關開啟。

---

### 步驟 4：載入套件
1. 點擊畫面左上角的 **「載入未打包項目」**（Edge 稱為「載入解壓縮的擴充功能」）。
2. 在彈出的檔案選擇器中：
   - 若要使用團隊整合版，請選擇資料夾：`Google試算表整合插件`（即包含 `manifest.json` 的該層資料夾）。
   - 若要使用個人單機版，請選擇資料夾：`單機AI辨識插件`。
3. 點擊「選擇資料夾」，瀏覽器擴充功能清單中便會出現套件卡片！

---

### 步驟 5：釘選到工具列
點擊瀏覽器右上角的 **拼圖圖示 🧩**，找到插件並點擊右側的 **圖釘 📌** 圖示，將其固定在工具列上以便隨時點擊。

---

## 🚀 初次設定與日常使用（以 Google 試算表整合版為例）

### 1. 首次設定連線
1. 點擊工具列上的綠色試算表圖示。
2. 展開 **「⚙️ Google 試算表連線設定」**。
3. 貼上管理員提供的 **Google Apps Script (GAS) Web App 網址**。
4. （可選）填寫預設面交地址。
5. 點擊 **「💾 儲存並測試連線」**，指示燈顯示綠色「已連線」即可開始使用。

### 2. 日常極速刊登流程
1. 開啟 **[扶輪公益網 (17rcn.org)](https://www.17rcn.org/)** 並登入帳號。
2. 進入物資刊登頁面（會員中心 ➔ 我要提供物資）。
3. 點擊右上角插件圖示，畫面將 **0 秒瞬間呈現** 當前待刊物資與縮圖。
4. 點擊下方 **「🚀 一鍵帶入此筆物資 (含照片)」**。
5. 表單所有欄位（品名、類別、數量、新舊、說明、地址）與 Google Drive 照片檔案將會**全自動填入並注入完成**！
6. 核對資料、輸入驗證碼後，點擊網頁上的「確認送出」即可！
