# 方案 B：Google 表單 + 試算表 (GAS) 5 分鐘極速設定手冊

本手冊將帶您完成 Google 表單、試算表與 Google Apps Script (GAS) 後端的串接設定。

---

## 📌 步驟 1：建立 Google 表單 (志工拍照端)

1. 開啟 [Google 表單 (Google Forms)](https://forms.google.com/)，新增一份空白表單。
2. 表單標題可命名為：**「扶輪公益物資上傳表單」**。
3. 依序新增以下問題欄位：
   - **欄位 1：物資照片 (必填)**
     - 題型選擇：**「檔案上傳」**。
     - 允許的特定檔案類型：開啟並勾選「**圖片**」。
     - 檔案數量上限：選擇 **「5」**（建議 1~3 張）。
     - 檔案大小上限：**「10 MB」**。
   - **欄位 2：志工姓名 / 聯絡人 (選填)**
     - 題型選擇：簡答。
   - **欄位 3：物資所在地址 (選填)**
     - 題型選擇：簡答（例如：`台北市大安區忠孝東路四段1號`）。
   - **欄位 4：物資現況補充說明 (選填)**
     - 題型選擇：簡答或段落（若志工有特殊想交代的細節）。

---

## 📌 步驟 2：建立關聯的 Google 試算表

1. 在 Google 表單編輯頁面頂端，切換到 **「回覆」** 標籤頁。
2. 點擊右上角綠色的 **「連結到試算表」** 按鈕。
3. 選擇 **「建立新的試算表」** ➔ 點擊「建立」。
4. 系統會自動為您打開新建立的 Google 試算表。

---

## 📌 步驟 3：設定專案名稱與貼入程式碼

1. 在剛打開的 Google 試算表選單列中，點擊 **「擴充功能」 ➔ 「Apps Script」**。
2. **為專案命名**：
   - 點擊左上角的預設文字 **「未命名專案 (Untitled project)」**。
   - 輸入專案名稱，推薦使用：**`扶輪公益網 AI 刊登助手後端`**（或 `RCN 扶輪公益網 - Goods AI Backend`）。
   - 點擊「重新命名」。
3. **貼入程式碼**：
   - 進入 Apps Script 編輯器後，將預設的 `function myFunction() {}` 全部清空。
   - 打開本專案中的 [`Code.gs`](file:///d:/Users/Thomas/Desktop/AI/新增資料夾/扶輪公益網插件/Google試算表整合插件/google_apps_script/Code.gs)，將全部內容**複製並貼入**編輯器。
4. 點擊上方的 💾 **「儲存專案」** 按鈕（或按 `Ctrl + S`）。

---

## 📌 步驟 4：設定 Gemini API Key

1. 在 Apps Script 編輯器左側導覽列中，點擊 ⚙️ **「專案設定 (Project Settings)」**。
2. 往下滑動找到 **「指令碼屬性 (Script Properties)」** 區塊。
3. 點擊 **「新增指令碼屬性」**：
   - **屬性 (Property)**：填入 `GEMINI_API_KEY`
   - **值 (Value)**：填入您的 Google Gemini API Key
4. 點擊 **「儲存指令碼屬性」**。

---

## 📌 步驟 5：一鍵初始化試算表結構

1. 回到 Apps Script 編輯器，左側切換回 **「< > 編輯器」**。
2. 在頂部的函式下拉選單中，選取 **`setupSheet`**。
3. 點擊 **「執行 (Run)」**。
4. *首次執行時 Google 會跳出授權視窗*：
   - 點擊「審查權限」➔ 選擇您的 Google 帳號 ➔ 點擊「進階 (Advanced)」 ➔ 點擊「前往... (不安全)」 ➔ 點擊「允許」。
5. 執行完成後，回到 Google 試算表，您會發現已建立好漂亮的紅色標題列（`時間戳記`、`狀態`、`物資品名`、`一級分類`、`詳細說明` 等）！

---

## 📌 步驟 6：設定表單送出自動觸發器 (重要！)

讓志工用手機一送出表單，雲端立刻自動呼叫 Gemini 辨識物資：

1. 在 Apps Script 編輯器左側導覽列中，點擊 ⏰ **「觸發條件 (Triggers)」**。
2. 點擊右下角的 **「+ 新增觸發條件」** 按鈕。
3. 進行以下設定：
   - **選擇要執行的功能**：選取 `onFormSubmit`
   - **選擇活動來源**：選取 **「來自試算表」**
   - **選取活動類型**：選取 **「提交表單時」**
4. 點擊 **「儲存」**（若跳出授權確認請一律允許）。

---

## 📌 步驟 7：部署為 Web App (供 Chrome 插件連線)

1. 在 Apps Script 編輯器右上角，點擊藍色按鈕 **「部署」 ➔ 「新增部署作業」**。
2. 點擊左側齒輪圖示 ⚙️，選取 **「網頁應用程式 (Web app)」**。
3. 設定如下：
   - **說明**：`v1`
   - **執行身分**：選取 **「我 (您的 Email)」**
   - **誰可以存取**：選取 **「所有人 (Anyone)」** *(務必選所有人，否則 Chrome 插件無法免登入讀取)*
4. 點擊 **「部署」**。
5. 複製產生的 **「網頁應用程式網址 (Web App URL)」**（格式類似 `https://script.google.com/macros/s/AKfycb.../exec`）。
6. **大功告成！** 將這串網址貼入 Chrome 擴充功能的「GAS 應用程式網址」欄位即可開始使用！

---

> 💡 **小撇步**：
> - **帳號與權限完全免煩惱**：
>   - 只要「建立表單」與「建立試算表」使用同一個 Google 帳號，所有人上傳的照片都會自動存進該帳號的雲端硬碟，**完全不需要手動去設定 Google Drive 的共用權限**！
>   - 外勤志工使用**任何 Google 帳號**皆可填表拍照；電腦發布人員使用插件時**甚至不需登入 Google**。
> - 若需要手動測試，可以執行 Apps Script 裡的 `processAllPendingRows` 函式，會自動把尚未辨識或標記為「待辨識」的行數全部辨識一次。

## 🛡️ 長青抗老化（Zero-IT-Maintenance）雙模型架構說明

為了避免未來 Google 退役舊模型（如舊版退役或推出新一代 Flash 模型）導致系統中斷，本系統後端採取純粹的**線上最新與次新 Top 2 Flash 模型**架構：

1. **雲端全自動執行（純粹使用線上 Top 2 Flash）**：
   - 系統後端會自動向 Google API (`/v1beta/models`) 查詢當前支援 `generateContent` 的所有 Flash 模型，依版本降冪排序後，**嚴格取最新 (Rank 1) 與次新 (Rank 2) 雙模型**輪替。
   - 完全不需要額外維護「系統設定」分頁，常態無人值守運作時不會有繁雜設定。
   - 若遭遇 503 / 429 高峰塞車，會自動啟動 **3 次退避重試（分別等待 3 秒、8 秒、20 秒）**；若遇 404 退役，自動無縫切換到次新備援模型。
2. **插件端手動指定模型（專責人員自由選擇）**：
   - 專責人員在 Chrome 插件端可以點擊 **「🔄 偵測可用模型」**，後端會自動回傳線上最新可用的 Flash 模型清單。
   - 當人員手動點擊 **「🔄 雲端重新辨識」** 或 **「🔄 重辨此筆」** 時，若下拉選單指定了特定模型，後端將**優先使用該選定模型**進行辨識。
   - 平時雲端背景自動觸發（`onFormSubmit` 或排程巡檢）則固定使用線上最新 Flash 模型，兩者互不干擾。

---

## 🔄 插件端手動重新辨識（專責人員免開 Apps Script）

若遇到極端尖峰導致自動重試仍失敗，發布專責人員**完全不需要進入 Apps Script 編輯器**，直接在 Chrome 插件操作即可：

1. **一鍵重新辨識所有失敗物資**：
   - 當試算表中有失敗項目時，插件上方會自動浮現警告條：`⚠️ 雲端有 X 筆物資辨識失敗`。
   - 點擊旁邊的 **「🔄 雲端重新辨識」** 按鈕，後端就會自動以選定之模型補跑所有失敗列，並即時更新待刊清單。
2. **單筆物資重新辨識**：
   - 在物資卡片右上角設有 **「🔄 重辨此筆」** 按鈕，專責人員若想指定特定模型重寫說明或重試，點一下即可單獨重跑該筆。

---

## ⏰ （進階可選）設定定時自動補跑排程

若希望系統完全「無人值守」，連插件按鈕都懶得按：
1. 在 Apps Script 編輯器左側點選 ⏰ **「觸發條件」** ➔ 右下角 **「+ 新增觸發條件」**。
2. 進行以下設定：
   - **選擇要執行的功能**：選取 `processAllPendingRows`
   - **選取活動來源**：選取 **「時間驅動」**
   - **選取時間型觸發條件類型**：選取 **「以小時為單位」** 或 **「分鐘計時器」**（例如每 30 分鐘或每小時）
3. 點擊 **「儲存」**。如此一來，即使遇到 Google 尖峰短暫失敗，系統每半小時都會自動在背景巡檢並補跑成功！

## 🧹 雲端空間維護與物資刪除（防止 Google Form 1GB 空間用盡）

Google 表單上傳照片預設上限通常為 1GB，若長時間累積照片容易滿載導致表單關閉無法填寫。本系統在插件端提供完善的空間維護工具：

1. **一鍵清理已刊登（Cleanup Published）**：
   - 點擊插件設定區的 **「清理已刊登」** 按鈕。
   - 系統會自動倒序掃描試算表，找出所有狀態為「已刊登」的列。
   - 將這些物資關聯的 **Google Drive 照片全數移至垃圾桶**，並刪除試算表資料列，**立刻釋放雲端硬碟與表單空間**！
2. **一鍵清理已略過（Cleanup Skipped）**：
   - 點擊插件設定區的 **「清理已略過」** 按鈕。
   - 系統會倒序掃描找出所有狀態為「略過」的列，將其 Drive 照片移至垃圾桶並刪除資料列，徹底釋放未發布廢照所佔據的雲端空間。
3. **單筆物資刪除與手動解鎖（Delete & Unlock）**：
   - 在物資卡片操作列提供 **「🗑️ 刪除」** 按鈕與 **「🔓 解除鎖定」** 按鈕。
   - 專責人員若發現重複填表、誤傳廢照或資格不符的物資，可直接點擊刪除。
   - **安全保護規則**：
     - **「刊登中」的鎖定物資不可刪除**（防止同仁正在發布時被誤刪；若需刪除可先點擊「🔓 解除鎖定」）。
     - 若同仁因關閉分頁或放棄導致物資停留在「刊登中」，**超過 20 分鐘後系統在下次讀取時將自動釋放回「待刊登」**，徹底杜絕死鎖。
     - 刪除時會同步將該物資的 Google Drive 照片移至垃圾桶並刪除資料列，徹底釋放空間。
   - 每次刪除均有防呆確認提示視窗，避免誤觸。
